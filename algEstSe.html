Conceito: Desvio de Fluxo Condicional

1. O que é uma condição?
Em programas normais, as linhas são executadas de cima para baixo em ordem sequencial. Uma Estrutura Condicional permite desviar esse caminho dependendo do resultado de uma expressão booleana (VERDADEIRO ou FALSO).
2. Condição Simples (se ... entao)
Avalia uma expressão. Se for Verdadeira, executa o bloco de código interno. Se for Falsa, ignora o bloco e continua a execução normalmente.
se (idade >= 18) entao escreval("Você é maior de idade.") fimse
3. Condição Composta (se ... entao ... senao)
Garante dois caminhos alternativos: um bloco é executado se a condição for Verdadeira, e outro bloco totalmente diferente é executado se for Falsa.
se (nota >= 7.0) entao escreval("Aluno APROVADO!") senao escreval("Aluno REPROVADO!") fimse
4. Condição Encadeada / Em Cascata
Usada para tratar mais de duas possibilidades. Quando a primeira condição é falsa, o programa faz um novo teste antes de tomar uma decisão final.
se (media >= 7.0) entao escreval("Aprovado") senao se (media >= 5.0) entao escreval("Recuperação") senao escreval("Reprovado") fimse fimse

Guia Completo: Tabela da Verdade

1. Como definir o Número de Linhas da Tabela?
O número total de combinações possíveis (linhas) é dado pela fórmula matemática:
Número de Linhas = 2n
Onde n é a quantidade de variáveis proposicionais (perguntas/entradas).
  • 2 variáveis (A, B): 22 = 4 linhas
  • 3 variáveis (A, B, C): 23 = 8 linhas
  • 4 variáveis (A, B, C, D): 24 = 16 linhas
2. Regra para Variar os valores de 0 (Falso) e 1 (Verdadeiro)
Para preencher a tabela cobrindo todas as possibilidades sem repetir nenhuma linha, aplicamos a regra de divisão sucessiva por 2 para a alternância de blocos:
  • 1ª Variável (Esquerda): Alterna blocos de 2n-1 zeros e uns. Exemplo para 8 linhas: 4 Zeros e 4 Uns.
  • 2ª Variável: Alterna a metade do bloco anterior. Exemplo para 8 linhas: 2 Zeros, 2 Uns, 2 Zeros, 2 Uns.
  • 3ª Variável: Alterna a metade da anterior. Exemplo: 1 Zero, 1 Um, 1 Zero, 1 Um.
  • Última Variável (Direita): Sempre alterna de 1 em 1 (0, 1, 0, 1...).
3. Resumo dos Operadores Lógicos
  • AND (E / e): Retorna 1 somente se TODAS as entradas forem 1.
  • OR (OU / ou): Retorna 1 se PELO MENOS UMA entrada for 1.
  • NOT (NÃO / nao): Inverte o valor (se for 0 vira 1, se for 1 vira 0). Ex: NOT(A).
