Manipulação de Arquivos em Python

1. Fechamento Automático vs. Manual

Com with open() (Boa Prática): O Python cuida do fechamento do recurso assim que o bloco indentado termina, mesmo se ocorrer uma exceção.

Com open() direto (Abordagem Manual): O arquivo permanece aberto na RAM até que a função .close() seja explicitamente executada pelo código.

2. Modos de Abertura de Arquivos

Modo Ação Comportamento se não existir
'w' Escrita: Sobrescreve todo o conteúdo do arquivo. Cria o arquivo.
'a' Anexar (Append): Adiciona novos dados ao final. Cria o arquivo.
'r' Leitura: Lê o conteúdo pré-existente. Gera erro FileNotFoundError.

3. Por que fechar arquivos é vital?

  • Evita vazamento de memória: Arquivos abertos consomem ponteiros do Sistema Operacional.
  • Garante a gravação (Flush): Os dados podem ficar presos no buffer da RAM e só serem gravados no disco após o .close().
  • Previne bloqueios de arquivo: Outros processos ou programas não conseguirão acessar/deletar um arquivo mantido aberto.
