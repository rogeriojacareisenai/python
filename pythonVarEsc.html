Entendendo Escopos e Variáveis em Python

O que é Escopo?

O Escopo define a região do código onde uma determinada variável é reconhecida e pode ser acessada ou modificada. Variáveis criadas em uma parte do código podem não estar visíveis para outras partes.

1. Escopo Global (Variáveis Globais)

  • Onde nasce: Criada fora de qualquer função, no corpo principal do programa.
  • Visibilidade: Pode ser lida por qualquer função ou bloco de código dentro do mesmo arquivo.
  • Tempo de vida: Permanece viva na memória durante toda a execução do programa.

2. Escopo Local (Variáveis Locais)

  • Onde nasce: Criada no bloco interno de uma função (ou recebida como parâmetro).
  • Visibilidade: Acessível apenas dentro da função onde foi declarada.
  • Tempo de vida: É criada quando a função é executada e destruída da RAM assim que a função termina (retorna).

3. O Sombreamento (Shadowing) e Conflito de Nomes

Se você criar uma variável local com o mesmo nome de uma variável global, o Python criará uma nova variável no escopo local. Ela "esconde" a global temporariamente dentro da função, mas não altera a variável global original.

4. A Regra LEGB de Busca

Quando você usa uma variável, o Python procura seu valor nesta ordem rigorosa:

  • L (Local): Busca dentro da função atual.
  • E (Enclosing): Busca em funções externas aninhadas (se houver).
  • G (Global): Busca no nível principal do arquivo.
  • B (Built-in): Busca nas funções nativas do Python (ex: len, print).

5. A Palavra-Chave global

Por padrão, funções podem ler variáveis globais, mas não podem modificá-las. Se você tentar alterar uma variável global dentro de uma função sem aviso prévio, o Python criará uma nova variável local.

Para dizer ao Python que você quer alterar a variável global original de dentro da função, deve-se usar a instrução: global nome_da_variavel.
