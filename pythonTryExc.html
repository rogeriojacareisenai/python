Tratamento de Exceções em Python (try / except)

O que é uma Exceção?

Uma exceção é um erro que ocorre durante a execução do programa (runtime). Quando o Python encontra um erro imprevisto (como dividir por zero ou converter um texto inválido em número), ele "lança" uma exceção. Se o erro não for tratado, o programa é interrompido abruptamente.

1. O Bloco try

Contém o código "de risco" — instruções que têm potencial para gerar um erro durante a execução. O Python tenta executar as linhas dentro deste bloco normalmente.

2. O Bloco except

Se ocorra algum erro dentro do bloco try, a execução do try é interrompida imediatamente e salta para o bloco except correspondente.

  • Você pode capturar erros específicos (ex: except ZeroDivisionError:).
  • Pode capturar o objeto do erro usando a sintaxe: except ZeroDivisionError as e:.

3. O Bloco else (Opcional)

Executado apenas se NENHUM erro tiver ocorrido no bloco try. É ideal para ações que só devem acontecer quando a operação do try for bem-sucedida.

4. O Bloco finally (Opcional)

Executado SEMPRE, independentemente de ter havido exceção ou não. É muito utilizado para tarefas de limpeza e liberação de recursos (ex: fechar conexão com banco de dados, fechar arquivos abertos).
