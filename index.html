Fundamentos da Computação

1.1. Funcionamento de um computador
O computador opera processando dados através de uma arquitetura básica composta por Entrada (Input) (teclado, mouse), Processamento (CPU/Processador), Memória (RAM para armazenamento temporário e HD/SSD para permanente) e Saída (Output) (monitor, caixas de som). Tudo é convertido e processado como sinais elétricos codificados no sistema binário (0s e 1s).
1.2. Programas de computador
1.2.1. Definição
Um programa de computador é uma sequência lógica e estruturada de instruções escritas em uma linguagem específica, projetada para ser executada pelo hardware a fim de realizar uma tarefa ou resolver um problema.
1.2.2. Tipos
Os programas dividem-se principalmente em:
  • Sistemas Operacionais/Base: Gerenciam o hardware (ex: Windows, Linux, macOS).
  • Aplicativos: Atendem a necessidades diretas do usuário (ex: navegadores, editores de texto, jogos).
  • Utilitários e Ferramentas: Auxiliam na manutenção do sistema ou no desenvolvimento (ex: antivírus, compiladores, IDEs).
1.2.3. Algoritmos
Um algoritmo é uma sequência finita de passos claros, bem definidos e não ambíguos para a solução de um problema (semelhante a uma receita de bolo). É a base conceitual antes de escrever o código em qualquer linguagem.
1.3. Linguagens de programação
1.3.1. Baixo nível
Linguagens próximas da arquitetura física da máquina (como Código de Máquina e Assembly). Oferecem alto controle de hardware e rápida execução, mas são difíceis de ler, escrever e não são portáveis.
1.3.2. Alto nível
Linguagens com sintaxe próxima da linguagem humana (geralmente em inglês), como Python, C# ou Java. São fáceis de aprender, portáveis e abstraem a complexidade do hardware.
1.3.3. Interpretada
O código-fonte é traduzido e executado linha a linha em tempo real por um Interpretador. Exemplo principal: Python e JavaScript.
1.3.4. Compilada
Todo o código-fonte é traduzido de uma só vez por um Compilador, gerando um arquivo executável direto na linguagem de máquina (ex: C, C++, Go).

Lógica de Programação

2.1. Abstração lógica
Capacidade de isolar os aspectos essenciais de um problema complexo, ignorando detalhes irrelevantes no momento. Permite focar na modelagem de soluções e na criação de estruturas de dados e funções reutilizáveis sem se preocupar com detalhes de implementação de baixo nível.
2.2. Álgebra booleana
Ramo da matemática que lida com variáveis de apenas dois valores lógicos: Verdadeiro (True/1) ou Falso (False/0). É a base da tomada de decisões em algoritmos através de operações lógicas fundamentais (E/AND, OU/OR, NÃO/NOT).
2.3. Fluxogramas
Representação gráfica de um algoritmo utilizando formas geométricas padronizadas (retângulos para ações, losangos para decisões, elipses para início/fim) conectadas por setas que indicam o fluxo de execução das instruções.
2.4. Operadores
2.4.1. Aritméticos
Símbolos usados para realizar cálculos matemáticos:
  • Adição (+), Subtração (-), Multiplicação (*), Divisão (/)
  • Divisão Inteira (//) e Módulo/Resto (%) em Python.
  • Exponenciação (**)
2.4.2. Relacionais
Utilizados para comparar dois valores, retornando um resultado booleano (True ou False):
  • Igual (==), Diferente (!=)
  • Maior que (>), Menor que (<)
  • Maior ou igual (>=), Menor ou igual (<=)
2.4.3. Lógicos
Combinam ou invertem expressões booleanas:
  • and (E): Retorna True se ambas as condições forem verdadeiras.
  • or (OU): Retorna True se pelo menos uma condição for verdadeira.
  • not (NÃO): Inverte o valor lógico (True vira False e vice-versa).
2.4.4. Expressões
Combinações de variáveis, constantes e operadores que são avaliadas pelo computador para produzir um único valor final. Podem ser aritméticas (resultam em número) ou lógicas/booleanas (resultam em True/False).
2.5. Teste de mesa
Processo manual no qual o programador segue passo a passo as instruções do algoritmo, anotando o valor de cada variável a cada linha executada. Serve para validar a lógica e encontrar erros (bugs) sem precisar rodar o código.
2.6. Refatoração
Prática de reestruturar e melhorar a organização interna do código existente (tornando-o mais limpo, legível e eficiente) sem alterar seu comportamento externo ou seu resultado final.
