Aula 01: Fundamentos da Computação

1.1. Arquitetura Básica do Computador

O funcionamento de um sistema computacional se baseia no fluxo contínuo de dados dividido em etapas centrais:

  • Entrada (Input): Dispositivos que capturam dados do mundo externo (ex: teclado, mouse, função input() do Python).
  • Processamento (CPU): A Unidade Central de Processamento busca instruções da memória e realiza operações aritméticas e lógicas.
  • Memória RAM: Espaço temporário (volátil) onde os dados do programa em execução e suas variáveis ficam armazenados.
  • Saída (Output): Apresentação dos dados processados (ex: tela, função print() do Python).

1.2. Programas e Algoritmos

Um Algoritmo é uma sequência finita, ordenada e não ambígua de passos para resolver um problema. Um Programa de Computador é a implementação de um algoritmo traduzido para uma sintaxe que o computador consiga processar.

1.3. Linguagens de Programação e Execução em Python

As linguagens dividem-se em diferentes níveis de abstração:

  • Baixo Nível (Linguagem de Máquina e Assembly): Diretamente compreendidas pelo hardware (código binário 0s e 1s), de alta complexidade humana.
  • Alto Nível (Python, C, Java): Próximas da linguagem humana (inglês), proporcionando alta abstração e produtividade.

Compilação vs. Interpretação: O Python é uma linguagem interpretada. O código-fonte em Python é traduzido linha por linha pela Python Virtual Machine (PVM) durante a execução, o que facilita o teste dinâmico e o aprendizado interativo.

Aula 02: Lógica de Programação

2.1. Abstração Lógica e Resolução de Problemas

A Abstração é a capacidade de decompor um problema complexo focando apenas nos detalhes relevantes e ignorando aspectos desnecessários. Em Python, isso se reflete na criação de modelos claros de dados e funções.

2.2. Álgebra Booleana e Operadores

A tomada de decisões no computador baseia-se na lógica booleana, que aceita apenas dois valores: True (Verdadeiro) e False (Falso).

Operadores Lógicos no Python:

  • and (E lógico): Retorna True somente se todas as condições forem verdadeiras.
  • or (OU lógico): Retorna True se pelo menos uma condição for verdadeira.
  • not (NÃO/Negação): Inverte o valor lógico da expressão.

Operadores Relacionais: Comparam valores e geram um resultado booleano:

  • == (Igual a), != (Diferente de)
  • > (Maior que), < (Menor que)
  • >= (Maior ou igual), <= (Menor ou igual)

Exemplo Prático em Python:

idade = 18
tem_carteira = True

# Estrutura condicional aplicando a Álgebra Booleana
if idade >= 18 and tem_carteira:
    print("Pode dirigir")
else:
    print("Não pode dirigir")

Aula 03: Algoritmo de Soma (VisuAlg)

3.1. Variáveis e Tipos de Dados

Variáveis são posições reservadas na memória RAM com um identificador (nome). Em pseudocódigo (VisuAlg) declaramos os tipos explicitamente, enquanto no Python os tipos são definidos dinamicamente:

  • Inteiro (int): Números sem casa decimal (ex: 10, -5).
  • Real (float): Números com ponto flutuante (ex: 10.5).

3.2. Comparativo: Pseudocódigo vs. Python

Algoritmo em VisuAlg:

Var
   n1, n2, soma : inteiro
Inicio
   escreva("Digite o primeiro número: ")
   leia(n1)
   escreva("Digite o segundo número: ")
   leia(n2)
   soma <- n1 + n2
   escreva("A soma é: ", soma)
Fimalgoritmo

Equivalente Direto em Python:

# Leitura e conversão explícita de tipo (casting)
n1 = int(input("Digite o primeiro número: "))
n2 = int(input("Digite o segundo número: "))

soma = n1 + n2  # Processamento

print(f"A soma é: {soma}")  # Saída formatada
